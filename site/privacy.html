Privacy

Your data stays on your Mac.

No account, cloud service, trackers, or telemetry. There is no ShakeBoard server waiting for your clipboard history.

The only network request is the update check you opt into: the appcast uses HTTPS, downloads are EdDSA-signed, and no system profile is sent.

Stored locally

What ShakeBoard keeps

Clipboard history, paste stacks, pinboards, preferences, OCR text, and files ShakeBoard owns live in ~/Library/Application Support/ShakeBoard. Existing Perch data is migrated there automatically on first launch. Files placed on the drag shelf are preserved or bookmarked; ShakeBoard does not relocate the originals.

Password managers and secure clipboard markers are excluded. You can add ignored apps, pause history, clear stored history, and hide individual cards from AI tools.

Optional

AI access starts off

The local shakeboard-mcp bridge for Claude Code and Codex is off by default. If you enable it, each verified client must ask for consent. Its five tools - recent, search, get, context, and stats - are read-only. They cannot change or delete clipboard records.

Hidden cards and excluded apps stay out of results. Image pixels and file contents are never returned. Requests are rate-limited and logged with time, verified client, tool, outcome, and counts, but never with clipboard text or search terms.

Know the limit

Redaction is best effort

Before eligible text is returned through MCP, ShakeBoard replaces known secret patterns and common personal data. Pattern-based redaction can miss unfamiliar or unusually formatted secrets. Keep AI access off when you do not need it, exclude sensitive apps, and use Hide from AI for sensitive cards.

Coming

Encrypted backup + sync

Encrypted backup and sync through a folder, network share, or iCloud Drive are planned. ShakeBoard does not provide cloud backup or sync today.

Inspect it

The code is open
